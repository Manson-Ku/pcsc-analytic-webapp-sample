WEB DEVICE BINDING

Device Binding 不需要綁死 Google Auth

SERVER-SIDE TRUTH

Device Binding 真正要回答的問題

這個 Browser / Device
→ 應綁定哪個 storeCode？

只要可信的 Web / Server 流程能 resolve storeCode，就能建立 Binding。

可用的 Store Resolution 來源

  • Web native account mapping
  • Enterprise SSO mapping
  • Google Workspace mapping
  • Admin provisioning

Google Workspace Login 可以是一種方法，但不是 protocol requirement。

簡化後： 如果 Web native account 已能可信地 resolve STORE_A，就直接建立 Device Binding；不需要為 Binding 再多做一次 Google OAuth。

SCENARIOS

Web 在不同情境下要載入哪種 Report

A

已綁定門市裝置 → 一般報表

BOOT → Binding=A001 → Store Context=A001 → GENERAL

一般資料如果可直接公開，嵌 GENERAL_PUBLIC；如果仍需 Google gate，嵌 GENERAL_RESTRICTED。

B

使用者進入進階分析

Open Analytics → ANALYTICS_RLS → Google Viewer → BigQuery RLS

Web 不需要建立自己的 GDS Human Authorization state。Report 採 Restricted + Viewer's Credentials，資料層由 BigQuery IAM + RLS 控制。

C

尚未綁定裝置

BOOT → Binding NONE → Trusted Web Flow → resolve storeCode → create Binding

這一步本身不要求 Google Auth。Binding 完成後回到 Scenario A，再依資料敏感度選 GDS Report Profile。
